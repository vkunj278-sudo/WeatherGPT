\# WeatherGPT



WeatherGPT is a conversational AI system for:



\- Weather forecasting

\- Weather alerts

\- Climate information

\- Natural language weather queries



\## Technology Stack



\- Python

\- FastAPI

\- React

\- AI/LLM

\- Weather APIs

\- Git/GitHub



\## Project Structure



\- backend → Backend API

\- frontend → User interface

\- data → Weather and climate data

\- models → AI/ML models
